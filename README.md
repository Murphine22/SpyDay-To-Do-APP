# SpyDay - Modern Task Management Application

## Overview
SpyDay is a modern, responsive task management application built with HTML, CSS, and JavaScript. It features a sleek interface with dark mode support, real-time digital clock, and animated interactions.

## Features
- 🌓 Dark/Light mode toggle with smooth transitions
- ⏰ Real-time digital clock display
- 📅 Task categorization (Daily/Weekly/Monthly/Yearly)
- 🎯 Priority levels with visual indicators
- 🎨 Glass morphism design elements
- 📱 Fully responsive layout
- ✨ GSAP-powered smooth animations
- 💾 Local storage persistence
- 🔍 Task filtering system

## Technologies Used
- HTML5
- CSS3 with Tailwind CSS
- Vanilla JavaScript
- GSAP (GreenSock Animation Platform)
- Animate.css
- Local Storage API
